# CIS 3339 Homework 1: Student Management System (Vue 3 + MongoDB)

A full-stack Student Management System built with Vue 3 (Composition API, Vue Router, Pinia), Node.js/Express, and MongoDB.

## Required Software
- Node.js (v18+ recommended) and npm
- MongoDB Community Edition (running locally)
- A modern web browser

## Required Environment Variables
The repository includes `backend/.env` configured for local MongoDB:
```env
PORT=3000
MONGODB_URI=mongodb://127.0.0.1:27017/cis3339_homework1
